ទិន្នន័យ & វិធីសាស្ត្រ

យើងមិនបង្កើតទិន្នន័យ epidemiological ដំបូងទេ។ យើង ប្រមូល (aggregate), តំរៀបរៀបចំ (normalise) និង ភ្ជាប់ (link back) ទៅប្រភពផ្លូវការ។ ចំណុចទិន្នន័យគ្រប់ទាំងអស់នៅលើផែនទី គឺអាចតាមដានបាន (traceable)។

វិធីសាស្ត្រ (Methodology)

  1. Active alerts ត្រូវបានទាញ (pull) ពី WHO DON, ProMED និង ECDC feeds ហើយបំបែកអ្វីដែលស្ទួន (de-duplicated)។
  2. News signals ត្រូវបានប្រមូលពី GDELT DOC 2.0 API និង Google News RSS ចំនួន ១៤ locale ។ ក្បួន NLP (client-side) ដំណើរការ:
    • ស្វែងរកឈ្មោះប្រទេស / ទីក្រុង (dictionary 35+ ប្រទេស)
    • ចាត់ប្រភេទ: Local / Imported / Response
    • ស្វែងរកចំនួនករណី / ស្លាប់
    • ប្រែប្រួលចំណងជើងទៅជាខ្មែរ (80+ phrase rules)
  3. Historical cases ត្រូវបានភ្ជាប់ទៅ country/region geographies (ISO 3166)។
  4. Endemic zones ត្រូវបានទាញចេញពី published long-term epidemiology — មិនមែនពី individual alerts ទេ។
  5. យើងចូលចិត្ត ការបង្ហាញការពិតដែលមិនពេញលេញ ជាជាងភាពច្បាស់លាស់មិនត្រឹមត្រូវ (incomplete transparency over false precision) — ពេលទិន្នន័យមានកម្រ យើងនិយាយដូច្នោះ។

ដែនកំណត់ (Limitations)

ចំណាំ: ផ្ទាំងនេះជាព័ត៌មានប៉ុណ្ណោះ — មិនមែនជាការណែនាំផ្នែកវេជ្ជសាស្ត្រទេ។ ប្រសិនបើអ្នកមានអាការៈ សូមទៅជួបគ្រូពេទ្យ។
  • ការទទួលបានការតាមដានសាធារណៈ (public surveillance) ជាទូទៅយឺតជាងព្រឹត្តិការណ៍ជាក់ស្តែង ដោយ ថ្ងៃ, សប្តាហ៍ ឬ ខែ។
  • ការរាយការណ៍ (reporting coverage) និង case definitions ខុសគ្នារវាងប្រទេស។
  • Country-level polygons មិនឆ្លុះបញ្ចាំងការប្រែប្រួលក្នុងប្រទេសទេ។
  • ការបកប្រែ (Khmer translation) ជា rule-based — មិនមែន AI ។ ពាក្យ English ខ្លះអាចនៅក្នុង title។
  • ចំនួននៅលើ pin = ចំនួននៃរបាយការណ៍ថ្មីៗ — មិនមែនករណីបញ្ជាក់ (confirmed cases) ទេ។
  • ការ refresh ប្រើ data/news.json ដែល commit ដោយ GitHub Actions រៀងរាល់ ៣០ នាទី — លេខថ្មីមាននៅក្រោយ cron run ខាងមុខ។

ប្រេក័ន្តការធ្វើបច្ចុប្បន្នភាព (Update frequency)

Auto

រៀងរាល់ ៣០ នាទី

GitHub Actions crons ដំណើរការ fetch-news.mjs (signals) និង fetch-data.mjs (totals) ។ ឯកសារ JSON ថ្មីត្រូវបាន commit ប្រសិនបើមានការផ្លាស់ប្តូរ។

On-demand

Manual trigger

Actions tab → "Refresh news signals" → "Run workflow" ។ ការ refresh ក្នុង browser ទាញ JSON ថ្មីបំផុត — ប្រសិន cron មិនទាន់ run លេខនឹងដូចគ្នា។
